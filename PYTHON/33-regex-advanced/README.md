# 33: 고급 정규표현식 (Advanced Regex) — 전방탐색, 역참조, 플래그

## 기초 복습
`\d`, `\w`, `\s`, `+`, `*`, `?`, `{n,m}`, 문자 클래스 `[a-z]`, 캡처 그룹 `(...)`

## 전방탐색 / 후방탐색
- `(?=...)` 전방탐색: 뒤에 이어지는 부분을 소비하지 않고 매치
- `(?!...)` 부정 전방탐색
- `(?<=...)` 후방탐색
- `(?<!...)` 부정 후방탐색

```python
re.findall(r"\d+(?=원)", "100원과 200원")  # ['100', '200']
```

## 역참조 (Backreference)
캡처한 그룹을 같은 패턴 안에서 `\1`처럼 재사용합니다. `(?P<name>...)`로 이름을 붙이고 `(?P=name)`으로 참조할 수 있습니다.

## 플래그
`re.IGNORECASE`, `re.MULTILINE`, `re.DOTALL`, `re.VERBOSE`, `re.ASCII`
