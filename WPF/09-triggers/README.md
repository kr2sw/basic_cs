# 09 - 트리거 (Triggers)

## 학습 목표
- PropertyTrigger로 속성 값 기반 시각적 변경
- DataTrigger로 데이터 값 기반 트리거
- EventTrigger로 이벤트 발생 시 애니메이션 실행
- MultiTrigger로 여러 조건 조합
- TriggerAction 이해

## 트리거 종류

| 트리거 | 설명 |
|--------|------|
| Trigger | 속성 값에 기반한 트리거 |
| DataTrigger | 데이터 바인딩 값에 기반한 트리거 |
| EventTrigger | 이벤트 발생 시 트리거 (주로 애니메이션) |
| MultiTrigger | 여러 조건이 모두 참일 때 |
| MultiDataTrigger | 여러 데이터 조건이 모두 참일 때 |
