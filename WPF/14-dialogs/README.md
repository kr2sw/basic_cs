# 14 - 대화상자 (Dialogs)

## 학습 목표
- MessageBox 사용법
- OpenFileDialog/SaveFileDialog 사용
- 사용자 정의 대화상자(Window) 만들기
- DialogResult 속성

## 대화상자 종류

| 종류 | 설명 |
|------|------|
| MessageBox | 간단한 알림/확인 대화상자 |
| OpenFileDialog | 파일 열기 대화상자 |
| SaveFileDialog | 파일 저장 대화상자 |
| FolderBrowserDialog | 폴더 선택 대화상자 |
| PrintDialog | 인쇄 대화상자 |
| 사용자 정의 Window | 모달/모덜리스 대화상자 |
