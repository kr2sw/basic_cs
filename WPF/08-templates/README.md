# 08 - 템플릿 (Templates)

## 학습 목표
- ControlTemplate으로 컨트롤 시각적 구조 재정의
- DataTemplate으로 데이터 표시 방식 정의
- TemplateBinding으로 템플릿 속성 바인딩
- ContentPresenter와 ItemsPresenter 사용

## 템플릿 종류

| 템플릿 | 설명 |
|--------|------|
| ControlTemplate | 컨트롤의 시각적 구조와 동작 정의 |
| DataTemplate | 데이터 객체의 시각적 표현 정의 |
| ItemsPanelTemplate | ItemsControl의 레이아웃 패널 정의 |
