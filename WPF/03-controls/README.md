# 03: 컨트롤 — 기본 WPF 컨트롤

Button, TextBox, CheckBox, RadioButton, Slider, ProgressBar 등 주요 WPF 컨트롤을 학습합니다.

## 실행

```bash
cd csharp && dotnet run
cd vbnet && dotnet run
```

## 주요 개념

- **ContentControl**: Button, Label 등 Content 속성을 가진 컨트롤
- **RangeBase**: Slider, ProgressBar, ScrollBar
- **ToggleButton**: CheckBox, RadioButton
- **ItemsControl**: ListBox, ComboBox
- **ToolTip**: 컨트롤 위에 표시되는 도움말
