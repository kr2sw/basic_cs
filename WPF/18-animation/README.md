# 18 - 애니메이션 (Animation)

## 학습 목표
- Storyboard를 사용한 애니메이션 정의
- DoubleAnimation, ColorAnimation, ThicknessAnimation
- EasingFunction으로 가속/감속 효과
- 코드 비하인드에서 애니메이션 제어

## 애니메이션 종류

| 애니메이션 | 설명 |
|-----------|------|
| DoubleAnimation | double 속성 애니메이션 (Width, Height, Opacity) |
| ColorAnimation | Color 속성 애니메이션 (Background, Foreground) |
| PointAnimation | Point 속성 애니메이션 |
| ThicknessAnimation | Thickness 속성 애니메이션 (Margin) |
