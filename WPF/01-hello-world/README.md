# 01: Hello World — 첫 WPF 앱

WPF(Windows Presentation Foundation)는 .NET 데스크톱 UI 프레임워크로, XAML 기반의 선언적 UI를 제공합니다.

## 실행

```bash
cd csharp && dotnet run    # C#
cd vbnet && dotnet run     # VB.NET
```

## 주요 개념

- **Window**: WPF 애플리케이션의 기본 창
- **XAML**: XML 기반 선언적 UI 언어
- **Code-behind**: XAML의 이벤트를 처리하는 C#/VB 코드
- **StackPanel**: 세로/가로로 컨트롤을 쌓는 레이아웃
- **Button.Click**: 버튼 클릭 이벤트 처리
