# 02: 레이아웃 — Grid, StackPanel, WrapPanel, DockPanel

WPF의 다양한 레이아웃 패널을 학습합니다.

## 실행

```bash
cd csharp && dotnet run
cd vbnet && dotnet run
```

## 주요 개념

- **Grid**: 행/열 기반 레이아웃 (가장 많이 사용)
- **StackPanel**: 가로/세로 쌓기
- **WrapPanel**: 공간 부족 시 자동 줄바꿈
- **DockPanel**: 상/하/좌/우 도킹
- **Margin / Padding**: 여백 설정
