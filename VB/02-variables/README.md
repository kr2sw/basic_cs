# 02: 변수 — 데이터 타입, 형변환, 상수

## 실행

```bash
dotnet run
```

## 주요 개념

- **Dim**: 변수 선언 키워드
- **데이터 타입**: Integer, Double, String, Boolean, Date, Char, Byte, Long, Short, Decimal
- **Option Explicit On**: 모든 변수 선언 강제 (기본 On)
- **Option Strict On**: 암시적 형변환 금지 (권장)
- **Const**: 상수 선언
- **CType / DirectCast / TryCast**: 형변환 함수
