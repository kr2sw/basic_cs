# 18: 데이터베이스 — ADO.NET 기초

## 실행

```bash
dotnet run
```

## 주요 개념

- **SqlConnection / SqlCommand**: SQL Server 연결 및 명령
- **SqlDataReader**: 데이터 읽기 (전방향 읽기 전용)
- **DataTable / SqlDataAdapter**: 테이블 형태 데이터 처리
- **매개변수화된 쿼리**: SQL Injection 방지
- **Connection String**: 연결 문자열

> 참고: 이 예제는 SQL Server LocalDB를 사용합니다.
> 연결 문자열은 환경에 맞게 수정해야 합니다.
