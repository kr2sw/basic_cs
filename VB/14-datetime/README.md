# 14: 날짜와 시간 — Date, TimeSpan

## 실행

```bash
dotnet run
```

## 주요 개념

- **Date**: 날짜와 시간을 나타내는 구조체 (VB의 Alias = DateTime)
- **Date.Now / Date.Today / Date.UtcNow**
- **TimeSpan**: 시간 간격
- **날짜 연산**: AddDays, AddMonths, AddYears
- **서식 지정**: ToString("yyyy-MM-dd")
- **Date.Parse / TryParse**: 문자열→날짜 변환
