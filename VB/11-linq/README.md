# 11: LINQ — Language Integrated Query

## 실행

```bash
dotnet run
```

## 주요 개념

- **LINQ 쿼리 구문**: `From/Where/Select/Order By`
- **LINQ 메서드 구문**: `.Where(Function...)`, `.Select(Function...)`
- **Function 람다**: VB의 람다 표현식
- **Aggregate**: 집계 함수 (Sum, Count, Average)
- **지연 실행 (Deferred Execution)**: 쿼리는 실제 사용될 때 실행
