# 08: 상속 — Inherits, 오버라이딩, 다형성

## 실행

```bash
dotnet run
```

## 주요 개념

- **Inherits**: 상속 선언
- **MyBase**: 부모 클래스 호출
- **Overridable / Overrides**: 메서드 오버라이딩
- **MustInherit / MustOverride**: 추상 클래스/메서드
- **NotInheritable**: 봉인 클래스 (상속 불가)
- **MyClass**: 오버라이딩 무시하고 현재 클래스 메서드 호출
- **Shadows**: 부모 멤버 숨기기
