# 19: 리플렉션과 어트리뷰트 — Attribute, Reflection

## 실행

```bash
dotnet run
```

## 주요 개념

- **Attribute**: 메타데이터 추가 ( `<AttributeUsage>`, `Inherits From Attribute`)
- **Reflection**: 런타임에 타입 정보 조사 ( `Type`, `GetType()`, `GetMethods()`)
- **Activator.CreateInstance**: 동적 객체 생성
- **CallByName**: 이름으로 멤버 호출 (VB 전용)
