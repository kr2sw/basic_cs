# 06: 문자열 — String 조작 함수

## 실행

```bash
dotnet run
```

## 주요 개념

- **문자열 연결**: `&`, `+`
- **문자열 보간**: `$"Hello, {name}!"`
- **String.Format**: 형식 지정
- **StringBuilder**: 효율적인 문자열 조립
- **문자열 함수**: Length, Substring, IndexOf, Replace, Split, Join, ToUpper, ToLower, Trim
- **Option Compare**: 이진/텍스트 비교 모드
