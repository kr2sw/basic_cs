# 02: Variables — 변수와 자료형

## 기본 자료형

| 타입 | 크기 (bytes) | 범위 | 서식 지정자 |
|------|-------------|------|-----------|
| `char` | 1 | -128 ~ 127 | `%c` |
| `short` | 2 | -32,768 ~ 32,767 | `%hd` |
| `int` | 4 | -2^31 ~ 2^31-1 | `%d` |
| `long` | 4 or 8 | -2^31 ~ 2^31-1 (32-bit) | `%ld` |
| `long long` | 8 | -2^63 ~ 2^63-1 | `%lld` |
| `float` | 4 | ±3.4E-38 ~ ±3.4E+38 | `%f` |
| `double` | 8 | ±1.7E-308 ~ ±1.7E+308 | `%lf` |
| `void` | - | 값 없음 | - |

## unsigned

`unsigned` 키워드로 양수만 저장 (범위가 2배).

## 형변환 (Casting)

- **암시적 형변환**: 작은 타입 → 큰 타입 (자동)
- **명시적 형변환**: `(타입)값`

## 상수

- `const int MAX = 100;` (const 키워드)
- `#define MAX 100` (매크로 상수)
