# 06: Pointers — 포인터

## 포인터 기초

- 포인터는 메모리 주소를 저장하는 변수입니다.
- `&`: 주소 연산자 (변수의 주소)
- `*`: 역참조 연산자 (주소가 가리키는 값)

```c
int x = 42;
int* ptr = &x;   // ptr은 x의 주소를 저장
printf("%d", *ptr);  // 42
```

## 포인터와 배열

배열 이름은 첫 요소의 주소와 같습니다.

```c
int arr[3] = {10, 20, 30};
arr == &arr[0]         // true
*(arr + 1) == arr[1]   // true
```

## NULL 포인터

아무 것도 가리키지 않는 포인터. 역참조하면 오류.
