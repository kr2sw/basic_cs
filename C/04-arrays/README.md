# 04: Arrays — 배열

## 1차원 배열

```c
int arr[5];                // 선언 (초기화되지 않음)
int arr[5] = {1, 2, 3};    // 일부 초기화 (나머지는 0)
int arr[] = {1, 2, 3};     // 크기 자동 결정
```

## 2차원 배열

```c
int matrix[3][4];
int matrix[][3] = {{1,2,3}, {4,5,6}};
```

## 배열과 포인터

- 배열 이름 = 첫 번째 요소의 주소
- `arr[i]` == `*(arr + i)`
- sizeof(arr) / sizeof(arr[0]) = 배열 길이
