# 13: Bit Manipulation — 비트 연산

## 비트 연산자

| 연산자 | 설명 |
|--------|------|
| `&` | AND |
| `|` | OR |
| `^` | XOR |
| `~` | NOT (1의 보수) |
| `<<` | 왼쪽 시프트 (2^n 곱) |
| `>>` | 오른쪽 시프트 (2^n 나눔) |

## 비트 플래그

여러 설정을 하나의 정수로 표현:

```c
#define READ    (1 << 0)  // 0001
#define WRITE   (1 << 1)  // 0010
#define EXECUTE (1 << 2)  // 0100
```
