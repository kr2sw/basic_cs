# 11: Preprocessor — 전처리기

## 전처리기 지시어

| 지시어 | 설명 |
|--------|------|
| `#include` | 파일 포함 |
| `#define` | 매크로 정의 |
| `#undef` | 매크로 해제 |
| `#if` / `#elif` / `#else` / `#endif` | 조건부 컴파일 |
| `#ifdef` / `#ifndef` | 매크로 정의 여부 확인 |
| `#pragma` | 컴파일러 지시 |
| `#error` | 에러 메시지 출력 |
| `#line` | 줄 번호 변경 |

## 매크로 연산자

- `#`: 문자열화 (stringification)
- `##`: 토큰 결합 (token pasting)
- `__VA_ARGS__`: 가변 인자

## 미리 정의된 매크로

| 매크로 | 설명 |
|--------|------|
| `__FILE__` | 현재 파일명 |
| `__LINE__` | 현재 줄 번호 |
| `__DATE__` | 컴파일 날짜 |
| `__TIME__` | 컴파일 시간 |
| `__STDC__` | ANSI C 준수 여부 |
