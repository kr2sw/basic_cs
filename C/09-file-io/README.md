# 09: File I/O — 파일 입출력

## 파일 열기/닫기

```c
FILE* fp = fopen("파일명", "모드");
// 작업 ...
fclose(fp);
```

## 파일 모드

| 모드 | 설명 |
|------|------|
| `"r"` | 읽기 |
| `"w"` | 쓰기 (덮어쓰기) |
| `"a"` | 추가 |
| `"r+"` | 읽기/쓰기 |
| `"w+"` | 읽기/쓰기 (덮어쓰기) |
| `"rb"` | 바이너리 읽기 |
| `"wb"` | 바이너리 쓰기 |

## 주요 함수

| 함수 | 설명 |
|------|------|
| `fprintf(fp, ...)` | 서식 출력 |
| `fscanf(fp, ...)` | 서식 입력 |
| `fgets(buf, n, fp)` | 한 줄 읽기 |
| `fputs(s, fp)` | 문자열 쓰기 |
| `fread(buf, size, count, fp)` | 바이너리 읽기 |
| `fwrite(buf, size, count, fp)` | 바이너리 쓰기 |
| `feof(fp)` | 파일 끝 확인 |
