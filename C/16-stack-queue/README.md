# 16: Stack & Queue — 스택과 큐

## 스택 (Stack)

LIFO (Last In, First Out) 구조입니다.

- `push`: 데이터 추가
- `pop`: 데이터 제거 (가장 최근)
- `peek` / `top`: 최상단 데이터 확인
- `isEmpty`: 비어있는지 확인

## 큐 (Queue)

FIFO (First In, First Out) 구조입니다.

- `enqueue`: 데이터 추가
- `dequeue`: 데이터 제거 (가장 오래된)
- `front`: 첫 데이터 확인
- `isEmpty`: 비어있는지 확인
