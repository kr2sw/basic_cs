# 17: Sorting — 정렬 알고리즘

## 정렬 알고리즘

| 알고리즘 | 평균 시간 | 최악 시간 | 공간 | 안정 |
|---------|----------|----------|------|------|
| 버블 정렬 | O(n²) | O(n²) | O(1) | O |
| 선택 정렬 | O(n²) | O(n²) | O(1) | X |
| 삽입 정렬 | O(n²) | O(n²) | O(1) | O |
| 퀵 정렬 | O(n log n) | O(n²) | O(log n) | X |
| 병합 정렬 | O(n log n) | O(n log n) | O(n) | O |
