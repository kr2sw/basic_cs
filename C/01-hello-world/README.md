# 01: Hello World — 기본 출력, 입력, 주석

## 컴파일과 실행

```bash
gcc main.c -o main   # 컴파일
./main               # 실행 (Linux/Mac)
main.exe             # 실행 (Windows)
```

## 기본 출력 (printf)

`printf("형식 문자열", 인자...)`로 출력합니다.
- `%d`: 정수, `%f`: 실수, `%c`: 문자, `%s`: 문자열
- `\n`: 줄바꿈, `\t`: 탭

## 기본 입력 (scanf)

`scanf("형식", &변수)`로 입력을 받습니다.
`&`는 변수의 주소를 의미합니다.
