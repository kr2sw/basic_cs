# 05: Functions — 함수

## 함수 정의

```c
반환타입 함수명(파라미터 타입 파라미터명) {
    // 코드
    return 반환값;
}
```

## 함수 프로토타입

함수를 사용하기 전에 선언하여 컴파일러에게 알립니다.

```c
int add(int a, int b);  // 프로토타입
```

## Call by Value

C는 기본적으로 값 복사 방식. 포인터를 사용하면 Call by Reference 흉내 가능.

## 재귀 함수 (Recursion)

자기 자신을 호출하는 함수. 종료 조건이 필수입니다.
