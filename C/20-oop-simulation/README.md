# 20: OOP Simulation — C에서 OOP 흉내내기

## C에서 객체 지향 프로그래밍

C는 객체 지향 언어가 아니지만, 구조체와 함수 포인터를 사용하여 OOP 개념을 흉내낼 수 있습니다.

### 구현 가능한 개념

| OOP 개념 | C 구현 방법 |
|---------|-----------|
| 캡슐화 | struct + header file (정보 은닉) |
| 상속 | 구조체 포함 (composition) |
| 다형성 | 함수 포인터 (vtable 패턴) |
| 생성자/소멸자 | init/destroy 함수 |

### VTable 패턴

함수 포인터를 구조체에 저장하여 가상 함수 테이블을 구현합니다.
