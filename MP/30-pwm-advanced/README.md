# 30: 고급 PWM — Servo, Sound, LED Brightness Curve

## 개요

기초 과정에서 LED 밝기를 다뤘다면, 이번 레슨에서는 PWM을 실무적으로 활용하는 **서보 모터, 부저 사운드, 감마 보정 LED 밝기**를 배웁니다. 같은 PWM이라도 주파수와 듀티 계산 방식이 전혀 다르게 사용됩니다.

## PWM의 세 가지 용도

| 용도 | 주파수 | 듀티 의미 |
|------|--------|-----------|
| 서보 | 50Hz (20ms 주기) | 펄스폭(0.5~2.5ms) = 각도 |
| 부저 | 음계 주파수(262~2000Hz) | 50% 고정, 주파수 = 음 높이 |
| LED | 수백 Hz~수 kHz | 밝기 비율 (감마 보정 필요) |

## 서보 모터 제어

서보는 50Hz 주기의 **펄스폭(Pulse Width)** 으로 각도를 지정합니다. 듀티 비율을 펄스폭/주기로 환산해야 합니다.

```python
# 90° → 펄스폭 1.5ms, 주기 20ms → 듀티비 1.5/20 = 0.075
servo.duty_u16(int(0.075 * 65535))  # ≈ 4915
```

## 부저 사운드

부저는 PWM **주파수**가 곧 음 높이입니다. 음계 주파수를 테이블로 정의하고, 듀티 50%에서 울렸다 꺼주는 방식으로 멜로디를 만듭니다.

```python
buzzer.freq(440)       # A4 라
buzzer.duty_u16(32768) # 50% 듀티 → 소리
```

## LED 밝기 감마 보정

사람의 눈은 밝기에 대해 **비선형**(감마 ≈ 2.2)으로 반응합니다. 선형 듀티로 50%로 낮추면 실제로는 훨씬 어둡게 보입니다. 그래서 입력을 감마 제곱으로 보정합니다.

```python
def gamma_brightness(brightness, gamma=2.2):
    return int(65535 * (brightness ** gamma))

# brightness=0.5 → duty ≈ 22700 (선형 32768보다 낮음)
```

## 실행/업로드 방법

2. **ampy**:

3. 시리얼 로그를 보면서 서보 스윕 → 멜로디 → LED 페이드 순서로 동작을 확인합니다.

## 핀 연결 (ESP32)

- 서보 신호 → GPIO13 (전원은 5V 별도 공급 권장)
- 부저 (+) → GPIO15, (−) → GND
- LED (+) → GPIO2 (저항 220Ω), (−) → GND

## 핵심 개념 요약

- 주파수·듀티를 용도에 맞게 해석 (각도/음높이/밝기)
- 서보는 50Hz + 펄스폭, 부저는 주파수, LED는 감마 보정
