# 40: 종합 프로젝트 — IoT 환경 모니터링 시스템

## 개요

중급 과정의 마지막 레슨입니다. 21~39장에서 배운 **I2C, 파일시스템, MQTT, 소켓, 상태 머신, 디스플레이 그래픽, 전원 관리**를 하나로 통합해, 실내 온습도를 측정해 클라우드로 전송하고 화면에 표시하는 **IoT 환경 모니터링 시스템**을 완성합니다.

## 시스템 구성

```
┌───────────────────────────── ESP32 ─────────────────────────────┐
│ DHT22 → 온습도 측정                                             │
│     │                                                          │
│ SSD1306 OLED ← 표시  |  상태 머신 → 알람 LED                     │
│     │                |    │                                    │
│ JSON 파일 ← 영속화    |   MQTT → 클라우드 (qos=1, retain)        │
└────────────────────────────────────────────────────────────────┘
```

## 통합된 기술 스택

| 21~39장 | 적용 지점 |
|---------|-----------|
| I2C/레지스터 (21) | I2C 버스로 OLED 구동 |
| MQTT 고급 (24) | QoS 1 + retained + will |
| 파일시스템 (25) | 마지막 측정값 JSON 영속화 |
| 소켓/네트워킹 (26) | Wi-Fi 연결 |
| 상태 머신 (28) | NORMAL ↔ ALARM 전이 |
| 디스플레이 그래픽 (31) | OLED 도형/텍스트 표시 |
| 전원 관리 (32) | 측정 주기 최적화 (플래시 절약) |

## 설계 원칙

- **관심사 분리**: 센서 읽기, 표시, 통신, 알람을 각각 분리
- **오류 내성**: 센서/MQTT 실패 시 이전 값을 유지하며 동작
- **저전력 배려**: 클라우드 보고는 30초 간격, 파일 쓰기는 상태 변경 시만
- **확장성**: `AlarmFSM`에 상태를 추가하거나 LoRa(33)로 대체 가능

## 주요 코드 구조

```python
# 상태 머신으로 알람 관리
alarm = AlarmFSM()
state = alarm.on_reading(reading)     # NORMAL ↔ ALARM

# MQTT QoS 1 + retain으로 최신 값 전달
client.publish(TOPIC, payload, qos=1, retain=True)

# 마지막 측정값 파일로 저장 (재부팅 후 복원)
with open("/data/last.json", "w") as f:
    json.dump(reading, f)
```

## 실행/업로드 방법

1. Wi-Fi/브로커 설정을 실제 값으로 바꾼 뒤 **Thonny IDE**에서 `MP/40-final-project/main.py` 실행(F5).
2. **ampy**:
   ```bash
   ampy --port COM3 put MP/40-final-project/main.py
   ampy --port COM3 run MP/40-final-project/main.py
   ```
3. OLED에 온습도가 표시되고, 시리얼에 측정/발행 로그가 출력됩니다.
4. PC에서 `mosquitto_sub -h test.mosquitto.org -t "iot/monitor/room1"`로 데이터 구독.
5. 손을 DHT22에 가까이 대어 28°C 이상이 되면 알람 LED가 켜지고 상태가 `ALARM`으로 바뀝니다.

## 확장 아이디어

- BME280으로 기압/고도 추가
- uasyncio(27)로 서버 기능을 백그라운드 태스크로 추가
- LoRa(33)로 원거리 센서 노드 연동
- OTA(39)로 원격 업데이트 적용
- 딥 슬립(32)으로 배터리 수명 연장
