# 33: LoRa — LoRa Module, Gateway, Long-Range Communication

## 개요

Wi-Fi는 수십 미터, BLE는 수 미터에 그치지만, **LoRa**는 저전력으로 **수 km~수십 km**까지 통신할 수 있는 장거리 무선 기술입니다. 이번 레슨에서는 SX1276 LoRa 모듈(RFM95 등)을 SPI로 제어해 두 보드 간 메시지를 주고받고, 게이트웨이 역할을 구현합니다.

## LoRa의 특성

- **장거리**: 도시 2~5km, 개활지 15km 이상
- **저전력**: 배터리로 수년 동작 가능
- **저속**: 0.3~50 kbit/s (아주 적은 데이터에 적합)
- 면허 없는 주파수 대역: 433MHz / 868MHz / 915MHz (지역별 규제 확인)

## 하드웨어 구조

```
┌────────────┐   SPI   ┌──────────────┐
│ ESP32      │◄───────►│ SX1276 (RFM95)│── 안테나
│ (호스트)    │   DIO0  │              │
└────────────┘         └──────────────┘
```

- ESP32는 SPI로 모듈의 레지스터에 접근합니다
- **DIO0 핀**으로 패킷 수신 인터럽트를 받습니다

## 패킷 송수신

```python
import sx127x   # LoRa 드라이버 (SPI + 레지스터 설정)
lora = sx127x.SX127x(spi, cs, reset, dio0, frequency=868)

lora.set_packet_mode()
lora.send(b"hello")            # 송신
data = lora.receive(timeout=5) # 수신 (패킷 모드)
```

`radio` / `sx127x` / `lora` 등 다양한 MicroPython 드라이버를 활용할 수 있습니다. 이번 레슨에서는 **개념과 프로토콜 구조**에 집중합니다.

## 게이트웨이와 에드혹

- **에드혹(점대점)**: 노드 A ↔ 노드 B 직접 통신
- **게이트웨이**: 한 노드가 모든 노드의 메시지를 수신해 인터넷/MQTT로 중계

main.py는 메시지 송신 노드와 게이트웨이 수신 노드 두 역할을 하나의 코드로 지원합니다.

## 실행/업로드 방법

1. 두 보드에 같은 `MP/33-lora/main.py`를 업로드합니다 (Thonny 또는 `ampy put`).
2. 보드의 GPIO로 역할을 선택합니다:
   - 보드 A: 송신 모드 (버튼 또는 자동 주기 송신)
   - 보드 B: 게이트웨이/수신 모드
3. 시리얼 모니터로 수신된 패킷과 RSSI(신호 세기)를 확인합니다. 안테나가 없으면 통신이 불가하므로 SMA 안테나를 연결하세요.

## 핀 연결 (ESP32 ↔ RFM95)

| RFM95 | ESP32 |
|-------|-------|
| MOSI | GPIO23 |
| MISO | GPIO19 |
| SCK | GPIO18 |
| NSS(CS) | GPIO5 |
| RST | GPIO14 |
| DIO0 | GPIO26 |
| VCC/GND | 3.3V / GND |

## 핵심 개념 요약

- LoRa: 저속·저전력·장거리, 수 km~수십 km
- ESP32가 SPI로 SX1276 레지스터 제어
- 패킷 모드 + DIO0 인터럽트로 송수신
- RSSI로 신호 세기 확인, 게이트웨이로 인터넷 중계
