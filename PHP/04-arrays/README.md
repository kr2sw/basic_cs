# 04: Arrays — 배열

## 배열 종류

- **인덱스 배열**: 숫자 키 사용 `[1, 2, 3]`
- **연관 배열**: 문자열 키 사용 `["name" => "Alice"]`

## 배열 함수

| 함수 | 설명 |
|------|------|
| `count()` | 요소 개수 |
| `array_push()` / `array_pop()` | 추가/제거 (끝) |
| `array_shift()` / `array_unshift()` | 추가/제거 (앞) |
| `sort()` / `rsort()` | 정렬 |
| `asort()` / `ksort()` | 연관 배열 정렬 |
| `in_array()` | 값 존재 확인 |
| `array_merge()` | 배열 합치기 |
| `array_keys()` / `array_values()` | 키/값 추출 |
| `array_map()` / `array_filter()` | 매핑/필터링 |
| `array_reduce()` | 축소 |
| `explode()` / `implode()` | 문자열 분할/결합 |
