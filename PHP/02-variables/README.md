# 02: Variables — 변수와 데이터 타입

## 기본 데이터 타입

| 타입 | 설명 | 예시 |
|------|------|------|
| `int` | 정수 | `42` |
| `float` | 실수 | `3.14` |
| `string` | 문자열 | `"hello"` |
| `bool` | 불리언 | `true`, `false` |
| `array` | 배열 | `[1, 2, 3]` |
| `null` | 값 없음 | `null` |
| `object` | 객체 | `new stdClass()` |

## 형변환

- `(int)`, `(float)`, `(string)`, `(bool)`, `(array)`
- `intval()`, `floatval()`, `strval()`

## 상수

- `define('NAME', value)` 또는 `const NAME = value`
- 한 번 정의하면 변경 불가
