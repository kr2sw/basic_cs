# 12: File Handling — 파일 입출력

## 파일 읽기/쓰기

| 함수 | 설명 |
|------|------|
| `file_get_contents()` | 파일 전체를 문자열로 읽기 |
| `file_put_contents()` | 문자열을 파일에 쓰기 |
| `file()` | 파일을 배열로 읽기 (줄 단위) |
| `fopen()` / `fclose()` | 파일 열기/닫기 |
| `fgets()` / `fwrite()` | 줄 단위 읽기/쓰기 |
| `fread()` / `fwrite()` | 바이트 단위 읽기/쓰기 |
| `feof()` | 파일 끝 확인 |
| `filesize()` | 파일 크기 |
| `file_exists()` | 파일 존재 확인 |
| `unlink()` | 파일 삭제 |
| `copy()` / `rename()` | 복사/이름 변경 |

## 디렉토리

| 함수 | 설명 |
|------|------|
| `mkdir()` | 디렉토리 생성 |
| `rmdir()` | 디렉토리 삭제 |
| `scandir()` | 디렉토리 목록 |
| `glob()` | 패턴으로 파일 검색 |
| `is_dir()` | 디렉토리 확인 |
| `is_file()` | 파일 확인 |

## fopen 모드

| 모드 | 설명 |
|------|------|
| `r` | 읽기 전용 |
| `w` | 쓰기 전용 (덮어쓰기) |
| `a` | 쓰기 전용 (추가) |
| `r+` | 읽기/쓰기 |
| `w+` | 읽기/쓰기 (덮어쓰기) |
