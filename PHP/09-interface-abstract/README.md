# 09: Interface & Abstract — 인터페이스, 추상 클래스, 트레이트

## 추상 클래스 (Abstract Class)

- `abstract` 키워드로 선언
- 추상 메서드(본문 없음)를 가질 수 있음
- **단일 상속**만 가능
- 생성자, 일반 메서드, 프로퍼티 가질 수 있음

## 인터페이스 (Interface)

- `interface` 키워드로 선언
- 모든 메서드는 `public abstract`
- **다중 구현** 가능
- 상수만 정의 가능 (프로퍼티 불가)

## Trait (PHP 5.4+)

- 코드 재사용 메커니즘 (다중 상속 대체)
- `use` 키워드로 클래스에 포함
- 충돌 시 `insteadof`, `as`로 해결

| 특징 | 추상 클래스 | 인터페이스 | Trait |
|------|-----------|-----------|-------|
| 다중 | 불가 | 가능 | 가능 |
| 구현 | 일부 가능 | 불가 | 완전 구현 |
| 프로퍼티 | 가능 | 불가 | 가능 |
