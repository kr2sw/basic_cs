# 01: Hello World — 기본 출력, 변수, 주석

## PHP 기본 문법

- PHP 코드는 `<?php ... ?>` 태그 안에 작성합니다.
- 파일 확장자는 `.php`입니다.
- `echo`, `print`로 출력합니다.

## 변수

- `$` 기호로 시작합니다 (예: `$name`).
- 타입 선언 없이 자동으로 결정됩니다.
- `var_dump()`로 타입과 값을 함께 확인할 수 있습니다.

## 주석

```php
// 한 줄 주석
# 한 줄 주석 (비권장)
/* 여러 줄 주석 */
```

## 실행

```bash
php index.php
```
