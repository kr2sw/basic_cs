# 05: Methods — 메서드

## 메서드 정의

```java
접근제어자 반환타입 메서드명(파라미터) {
    // 구현
    return 반환값;
}
```

## 메서드 특징

- **오버로딩 (Overloading)**: 같은 이름, 다른 파라미터로 여러 메서드 정의
- **가변인자 (Varargs)**: `타입... 변수명`으로 0개 이상의 인자 전달
- **Call by Value**: Java는 항상 값 복사 (참조형은 참조값 복사)
- **return**: 메서드 종료 및 값 반환 (`void`면 생략 가능)
