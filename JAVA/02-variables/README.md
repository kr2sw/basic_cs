# 02: Variables — 변수, 데이터 타입, 형변환

## 기본형 (Primitive Types)

| 타입 | 크기 | 범위 |
|------|------|------|
| `byte` | 1B | -128 ~ 127 |
| `short` | 2B | -32,768 ~ 32,767 |
| `int` | 4B | -2^31 ~ 2^31-1 |
| `long` | 8B | -2^63 ~ 2^63-1 |
| `float` | 4B | ±3.4E-38 ~ ±3.4E+38 |
| `double` | 8B | ±1.7E-308 ~ ±1.7E+308 |
| `char` | 2B | 0 ~ 65,535 (유니코드) |
| `boolean` | 1B | true / false |

## 참조형 (Reference Types)

클래스, 인터페이스, 배열 등 기본형을 제외한 모든 타입. `null`을 가질 수 있습니다.

## 형변환 (Casting)

- **자동 형변환**: 작은 타입 → 큰 타입 (묵시적)
- **강제 형변환**: 큰 타입 → 작은 타입 (명시적, 데이터 손실 가능)
