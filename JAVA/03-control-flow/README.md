# 03: Control Flow — 조건문과 반복문

## 조건문

### if / else if / else
```java
if (조건) {
    // 조건 true
} else if (다른 조건) {
    // 다른 조건 true
} else {
    // 모두 false
}
```

### switch (Java 14+)

Java 14부터 화살표(`->`) 연산자와 `yield` 키워드가 추가되어 더 간결하게 사용 가능합니다.

## 반복문

- **for**: 반복 횟수가 정해져 있을 때
- **while**: 조건이 true인 동안 반복
- **do-while**: 최소 1회 실행 후 조건 검사
- **향상된 for문**: 배열이나 컬렉션 순회
