# 01: Hello World — 기본 출력, 입력, 주석

## 기본 출력 (System.out)

`System.out.println()`은 값을 출력하고 줄바꿈합니다. `System.out.print()`는 줄바꿈 없이 출력합니다.

## 서식 출력 (printf)

`System.out.printf("%d, %s", num, str)` 형식으로 서식 지정 출력이 가능합니다.

## 주석 (Comments)

- 한 줄 주석: `//`
- 여러 줄 주석: `/* ... */`
- 문서 주석: `/** ... */` (javadoc)

## 컴파일 및 실행

```bash
javac Main.java   # 컴파일 → Main.class 생성
java Main         # 실행
```
