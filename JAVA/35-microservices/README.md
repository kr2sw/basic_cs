# 35: Microservices — 마이크로서비스

## 모놀리식 vs 마이크로서비스

| 구분 | 모놀리식 | 마이크로서비스 |
|------|----------|----------------|
| 구조 | 하나의 애플리케이션 | 여러 개의 독립 서비스 |
| 배포 | 통째로 배포 | 서비스별 배포 |
| DB | 하나의 DB | 서비스별 DB (분리) |
| 확장 | 전체 확장 | 필요한 서비스만 확장 |
| 복잡도 | 초기엔 단순 | 분산 시스템 복잡도 증가 |

## 서비스 분리 기준

- **도메인 경계**: 주문/결제/회원은 각각 다른 도메인
- **팀 구조**: 팀마다 서비스를 소유 (Conway's Law)
- **독립 배포**: 한 서비스 수정이 다른 서비스에 영향 없도록

## REST 통신

서비스들은 HTTP REST 로 통신합니다.

```java
ResponseEntity<User> user = restTemplate.getForEntity(
    "http://user-service/api/users/" + id, User.class);
```

## 서비스 디스커버리

- 서비스 위치를 중앙 레지스트리에서 찾음
- Eureka, Consul 등이 대표적
- 여러 인스턴스는 로드밸런싱으로 분산 처리

## 내결함성 (Resilience)

- **서킷 브레이커**: 연속 실패 시 회로를 열어 빠른 실패
- **재시도/타임아웃**: 일시적 장애 복구
- **벌크헤드**: 장애가 다른 서비스로 전파되지 않게 격리

## 실행

```bash
cd JAVA/35-microservices
javac Main.java && java Main
```

> 실제 HTTP 없이 서비스 레지스트리, 게이트웨이 라우팅,
> 서킷 브레이커를 메모리로 구현해 마이크로서비스 개념을 확인합니다.
