# 36: 데이터 수집 — Data Acquisition

고정 주기로 센서를 샘플링하고, 시리얼 플로터와 CSV 형식으로 데이터를 수집·분석합니다.

## 학습 내용
- 샘플링 주기와 안티에일리어싱 개념
- 고정 주기 샘플링 (millis 기반)
- 시리얼 플로터용 출력 형식
- CSV 출력과 통계(최소/최대/평균) 계산
- SD 카드(23장) 로깅과 연동

## 샘플링 개념

데이터를 얼마나 자주 읽을지가 **샘플링 주기**입니다. 주기가 일정해야 신호 분석이 정확합니다. 밝기(밝은 빛이 천천히 변함)는 느린 주기로, MPU6050 자세(빠르게 변함)는 빠른 주기로 수집합니다.

```cpp
// 100ms(10Hz) 고정 주기 샘플링
static unsigned long lastSample = 0;
if (millis() - lastSample >= 100) {
  lastSample = millis();
  int value = analogRead(A0);  // 샘플링
}
```

## 시리얼 플로터 출력

시리얼 플로터는 `label:값` 형태로 분리된 여러 채널을 그래프로 그려줍니다.

```cpp
Serial.print("raw:");     // 채널 1
Serial.print(analogRead(A0));
Serial.print(" smooth:"); // 채널 2
Serial.println(smoothed);
```

## CSV 출력

엑셀/파이썬에서 분석하기 쉽도록 콤마로 구분해 출력합니다.

```cpp
Serial.print(millis());   // 시간
Serial.print(",");
Serial.println(value);    // 값
```

## 이동 평균 (노이즈 제거)

노이즈가 많은 신호는 최근 N개의 평균으로 부드럽게 만듭니다.

```cpp
smooth = smooth * 0.9 + value * 0.1;  // 지수 이동 평균
```

## 회로 연결

| 부품 | Arduino Uno |
|------|-------------|
| 가변저항 | A0 |
| 버튼 (선택) | D2, 반대쪽 GND |

## 실행 방법

1. 이 챕터의 `.ino`를 업로드합니다.
2. **도구 → 시리얼 플로터**(9600)를 열면 `raw`와 `smooth` 그래프가 그려집니다.
3. 가변저항을 움직여 원본과 평균 신호의 차이를 확인합니다.
4. 시리얼 모니터에서 CSV 형식과 통계(최소/최대/평균) 출력을 확인합니다.

## 응용 아이디어

- 23장(SD 카드)과 결합한 장기 데이터 로거
- 33장(PID)의 제어 입력 신호 모니터링
- 40장(종합 프로젝트) 기상 관측소의 데이터 수집부
