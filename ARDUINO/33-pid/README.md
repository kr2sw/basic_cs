# 33: PID 제어 — PID Control

PID(비례·적분·미분) 제어 알고리즘을 직접 구현하여 온도/모터 같은 시스템을 목표값으로 정밀하게 제어합니다.

## 학습 내용
- 제어 루프 개념 (목표값 vs 현재값 vs 제어 출력)
- PID 공식과 각 항의 역할 (P, I, D)
- PID 루프를 직접 구현하기
- 시리얼로 이득(Kp/Ki/Kd) 튜닝

## PID 개념

PID는 측정값(현재 온도)을 목표값(설정 온도)에 맞추기 위해 제어 출력을 계산합니다.

```
출력 = Kp × 오차 + Ki × 오차 적분 + Kd × 오차 변화율
```

- **P(비례)**: 오차에 비례해 크게 반응 → 반응 속도 담당
- **I(적분)**: 남는 오차를 오래 쌓아 보정 → 정상 상태 오차 제거
- **D(미분)**: 오차 변화를 예측해 반발 → 진동 억제

```cpp
double error = setpoint - measured;
integral += error * dt;
double derivative = (error - lastError) / dt;
double output = Kp * error + Ki * integral + Kd * derivative;
```

## 샘플링 시간 (dt)

PID는 일정한 주기로 계산해야 안정적입니다. `millis()` 차이로 dt(초)를 구해 적분/미분에 사용합니다.

```cpp
float dt = (millis() - lastTime) / 1000.0;
lastTime = millis();
```

## 안티와인드업 (적분 제한)

적분 항이 커지면 출력이 포화되어 회복이 느려집니다. 적분 값을 일정 범위로 제한합니다.

```cpp
integral = constrain(integral, -100, 100);
output = constrain(output, 0, 255);  // PWM 출력 범위
```

## 플랜트 시뮬레이션

이 챕터는 실제 발열체 대신 **시뮬레이션 플랜트**로 안전하게 실습합니다. 제어 출력에 따라 온도가 상승하고, 주변 온도로 천천히 식는 동작을 모사합니다.

```cpp
double heating = output / 255.0;              // 히터 강도 0~1
measured += (heating * 5.0 - (measured - 20.0) * 0.02) * dt;
```

PWM 출력은 LED(핀 9)로 확인할 수 있습니다. 밝기 = 히터 출력.

## 회로 연결

| 부품 | Arduino Uno |
|------|-------------|
| LED (+220Ω) | D9 (제어 출력 표시) |
| 가변저항 (선택) | A0 → 목표값으로 사용 |

> 이 챕터의 계산은 소프트웨어 시뮬레이션이므로 LED 하나로 충분합니다.

## 실행 방법

1. 이 챕터의 `.ino`를 업로드하고 시리얼 플로터(도구 → 시리얼 플로터)를 엽니다.
2. 시리얼 모니터(9600)에서 명령으로 설정값과 이득을 바꿉니다.
   - `s 35` → 목표 온도 35℃
   - `kp 3` → 비례 이득 3
   - `ki 0.3` → 적분 이득 0.3
   - `kd 0.05` → 미분 이득 0.05
3. 목표값 주위로 진동이 줄고 정확히 따라가는지 확인하며 튜닝합니다.
