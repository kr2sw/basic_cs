# 40: 종합 프로젝트 — Final Project

배운 내용을 모두 결합한 **기상 관측소**를 만듭니다. 온습도·기압 센서와 RTC, SD 카드, OLED를 한 시스템으로 통합합니다.

## 프로젝트 개요

| 구성 요소 | 역할 | 관련 챕터 |
|-----------|------|-----------|
| DHT11/DHT22 | 온습도 측정 | 13장 |
| BMP280 | 기압·고도 측정 | 21장 |
| DS3231 RTC | 실제 시각 타임스탬프 | 27장 |
| SD 카드 | CSV 로그 저장 | 23장 |
| OLED | 실시간 표시 | 30장 |
| 시리얼 | 디버그/데이터 출력 | 36장 |

```
[센서들] → 샘플링 → OLED 표시 + SD CSV 저장 + 시리얼 출력
```

## 시스템 설계 (비블로킹)

모든 작업을 millis() 스케줄러(35장)로 관리해 서로 간섭 없이 동작합니다.

- 2초 주기: 센서 샘플링
- 1초 주기: OLED 갱신
- 30초 주기: SD 카드 로그 저장

## 회로 연결

| 모듈 | Arduino Uno |
|------|-------------|
| DHT11/22 | D2 (VCC 5V, GND) |
| BMP280 | VCC 3.3V, GND, SDA A4, SCL A5 |
| DS3231 | VCC 5V, GND, SDA A4, SCL A5 |
| SD 모듈 | CS D10, MOSI D11, MISO D12, SCK D13 |
| OLED | VCC 5V, GND, SDA A4, SCL A5 |

> I2C 장치 3개(BMP280, DS3231, OLED)는 주소가 달라 같은 버스에서 공존합니다. SD 카드는 SPI를 사용하므로 핀 충돌이 없습니다.

## 실행 방법

1. 설치할 라이브러리: `DHT sensor library`, `Adafruit BMP280 Library`, `RTClib`, `Adafruit SSD1306`, `Adafruit GFX Library`
2. 위 회로를 연결하고, SD 카드는 FAT32로 포맷합니다.
3. 이 챕터의 `.ino`를 업로드하고 시리얼 모니터(9600)를 엽니다.
4. OLED에 온도/습도/기압이 표시되고, 30초마다 CSV가 SD에 저장됩니다.
5. 전원을 껐다 켜도 RTC 배터리로 시각이 유지되어 로그가 이어집니다.

## 로그 형식

`weather.csv` 파일에는 RTC의 실제 시각이 타임스탬프로 기록됩니다.

```
2026-07-31 12:00:00,24.5,55.0,1013.2
2026-07-31 12:00:30,24.6,54.0,1013.1
```

## 확장 아이디어

- **로봇 제어 프로젝트**: 초음파(12장) + DC모터(15장) + 상태 머신(34장)으로 자율 주행 로봇
- WiFi(25장) + MQTT(26장)로 클라우드 대시보드 연동 (39장)
- GPS(31장)를 붙여 이동형 기상 관측소로
- 배터리 + 딥 슬립(32장)으로 야외 설치
