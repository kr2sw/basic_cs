# 35: 마이크로서비스 — Microservices

마이크로서비스는 앱을 독립적으로 배포·확장 가능한 작은 서비스들로 나누는
아키텍처입니다. 서비스 간 HTTP 통신과 서비스 레지스트리 패턴을 학습합니다.

## 핵심 개념

- **서비스 분리** — 도메인 단위(주문, 결제, 배송)로 독립 배포
- **HTTP 통신** — REST 기반으로 서로 호출
- **서비스 레지스트리** — 서비스 위치(URL)를 관리하는 중앙 등록소
- **내결함성** — 한 서비스가 죽어도 전체가 무너지지 않게 (재시도, 회로 차단)

## 서비스 레지스트리 패턴

서비스 인스턴스가 시작되면 레지스트리에 등록하고, 종료 시 등록을 해지합니다.
클라이언트는 레지스트리에서 위치를 조회해 호출합니다.

```csharp
registry.Register("order-service", "http://host1:5001");
registry.Register("order-service", "http://host2:5001");

var instances = registry.Resolve("order-service"); // 라운드로빈으로 선택
```

## 실행

```bash
dotnet run
```

## 핵심 요약

- 각 마이크로서비스는 독립적으로 배포·스케일됩니다.
- 레지스트리로 서비스 위치를 동적으로 관리합니다.
- HTTP 클라이언트에 재시도/타임아웃을 걸어 부분 장애를 견딥니다.
