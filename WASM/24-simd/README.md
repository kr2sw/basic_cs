# 24: SIMD — v128, 128비트 벡터 연산

SIMD(Single Instruction, Multiple Data)는 128비트 `v128` 값 하나에 4~16개 데이터를 넣고 한 번의 연산으로 처리합니다. 이미지 처리, 오디오, 머신러닝 추론 같은 데이터 병렬 작업에 적합합니다.

## v128 래인 구성

| 명령어 | 래인 개수 | 래인 폭 |
|--------|-----------|---------|
| `i8x16` | 16 | 8비트 정수 |
| `i16x8` | 8 | 16비트 정수 |
| `i32x4` | 4 | 32비트 정수 |
| `i64x2` | 2 | 64비트 정수 |
| `f32x4` | 4 | 32비트 부동소수 |
| `f64x2` | 2 | 64비트 부동소수 |

## v128.load / v128.store

```wat
;; 메모리 16바이트를 v128로 로드
(v128.load (local.get $addr))

;; v128 값을 메모리에 저장
(v128.store (local.get $dst) (v128.load (local.get $src)))
```

## 벡터 연산

```wat
;; 4개 i32를 동시에 더함
(i32x4.add (v128.load $a) (v128.load $b))

;; 4개 f32를 동시에 곱함
(f32x4.mul (v128.load $a) (v128.load $b))

;; 모든 래인에 같은 값을 넣음
(i32x4.splat (i32.const 1))
```

## 래인 추출

```wat
;; 0번째 래인만 i32로 꺼냄
(i32x4.extract_lane 0 (local.get $v))
```

## 스칼라 대비 성능

정수 덧셈 루프를 비교하면 SIMD가 한 번에 4개를 처리하므로 (로드/스토어 오버헤드 제외) 이론상 최대 4배, 부동소수 곱셈은 최대 4배, i8 연산은 최대 16배 빠를 수 있습니다.
