# 02: Template Syntax — 템플릿 문법

## 보간법 (Interpolation)

- `{{ message }}`: 텍스트 보간
- `{{ number + 1 }}`: 표현식 가능
- `{{ ok ? 'YES' : 'NO' }}`: 삼항 연산자

## Directives (디렉티브)

`v-` 접두사가 있는 특수 속성입니다.

| 디렉티브 | 약어 | 설명 |
|---------|------|------|
| `v-bind` | `:` | 속성 바인딩 |
| `v-on` | `@` | 이벤트 리스너 |
| `v-if` | - | 조건부 렌더링 |
| `v-for` | - | 리스트 렌더링 |
| `v-model` | - | 양방향 바인딩 |
| `v-html` | - | raw HTML 출력 |
| `v-once` | - | 한 번만 렌더링 |
| `v-show` | - | display 토글 |

## v-html 주의

사용자 입력을 `v-html`로 렌더링하면 **XSS 취약점**이 발생할 수 있습니다.
신뢰할 수 있는 콘텐츠에만 사용하세요.
