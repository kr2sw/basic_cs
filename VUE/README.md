# Vue.js 기초 강의 (20개 챕터)

Vue.js 프레임워크의 기초부터 고급 개념까지 학습할 수 있는 예제 모음입니다.

```bash
npm create vue@latest  # 프로젝트 생성
cd 프로젝트 && npm install && npm run dev
```
